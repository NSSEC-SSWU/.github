## About Us

Welcome to the GitHub organization of the Networked System Security Lab (NSSEC) at Sungshin Women's University, led by Prof. Seongmin Kim.

We investigate security challenges in emerging computing and networking technologies, with an emphasis on building secure, efficient, and practical systems.

> Design a practical and secure computing/networked system

## Research Areas

### Cloud Computing & System Security

- Trusted Execution Environments (TEE) and Confidential Computing
- Container and Microservice Security
- Serverless Computing and Function-as-a-Service (FaaS)
- Infrastructure as Code (IaC) Security
- Software Supply Chain Security

### Networked Systems & Network Security

- IoT and Edge Cloud Security
- 5G Network Security
- Software-Defined Networking (SDN) and Network Function Virtualization (NFV)
- Network Middleboxes
- Tor, Privacy, and Anonymity

### Digital Forensics

- Browser and Web Forensics
- Cloud Forensics
- Dark Web Forensics
- Digital Forensics of Emerging Applications and Services

### Emerging Research Topics

- Privacy-Preserving Federated Learning
- Security for Artificial Intelligence
- Post-Quantum Cryptography and Crypto Agility
- SmartNIC and Confidential Computing
